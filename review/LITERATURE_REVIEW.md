# Literature supporting the code-review decisions

Search/access date: **28 October 2026**. This was a targeted implementation
review, not an exhaustive novelty search. Interfaces used were the available
web search engines, ACL Anthology, official AAAI proceedings, arXiv HTML/PDF,
Anthropic's primary engineering report, and SQLite documentation. Sider Scholar
was not used. No paid database coverage is claimed.

Representative queries included `semantic chunking computational cost`,
`metadata contextual retrieval COCO captions`, `late chunking contextual chunk
embeddings`, `query rewriting retrieval augmented language models`, and `RAG
counterfactual robustness`. Original methods/results/limitations were inspected
where available. The COCO 2015 PDF fetch failed through one interface; the
implemented corpus facts below come from the actual approved files, not that
abstract. Metadata, dates and publication status were checked against publishers.

| Source and verified status | Established contribution | Application and limits for this project |
|---|---|---|
| Qu, Tu & Bao, **Is Semantic Chunking Worth the Computational Cost?**, Findings of NAACL 2025, pp. 2155–2177. [Paper](https://aclanthology.org/2025.findings-naacl.114.pdf), [record/DOI](https://aclanthology.org/2025.findings-naacl.114/). | Compares fixed, breakpoint and clustering segmentation on document/evidence retrieval and answer generation; gains from semantic segmentation are inconsistent in their experiments. The authors acknowledge context-free sentence embeddings and limited intrinsic quality measures as limitations. | Supports measuring benefit before adding semantic models. It does not prove that semantic chunking never helps, or directly study COCO. Our short-caption measurements and donor diagnostic provide corpus-specific evidence. |
| de Moura Júnior, Lelong & Blangero, **Adaptive Chunking: Optimizing Chunking-Method Selection for RAG**, LREC 2026, pp. 11535–11551. [Paper](https://aclanthology.org/2026.lrec-1.903.pdf), [record](https://aclanthology.org/2026.lrec-1.903/). | Combines structural/contextual chunk metrics to select a strategy per document; evaluates formal legal, technical and social-science documents. Their size-compliance bounds are 100–1,100 tokens. | Supports respecting document structure. Those size thresholds should not be imported into a corpus whose longest observed caption is 65 tokens. Their own limitations call for further validation on informal/multimodal material. |
| Günther et al., **Late Chunking: Contextual Chunk Embeddings Using Long-Context Embedding Models**, arXiv:2409.04701, inspected v3 dated 7 July 2025. [Full text](https://arxiv.org/html/2409.04701v3), [record](https://arxiv.org/abs/2409.04701). Treated here as an arXiv preprint; no journal/conference status inferred. | Encodes document tokens jointly before pooling chunks so they retain surrounding context; evaluates retrieval tasks and documents cases where ordinary chunking is comparable or better. | No long coherent document surrounds each independent COCO caption. Encoding unrelated images jointly would manufacture cross-image context. No long-context embedder is added. |
| Wang et al., **Document Segmentation Matters for Retrieval-Augmented Generation**, Findings of ACL 2025, pp. 8063–8075. [Paper](https://aclanthology.org/2025.findings-acl.422.pdf), [record](https://aclanthology.org/2025.findings-acl.422/). | PIC uses document summaries to guide sentence grouping and reports improvements on open-domain QA benchmarks. | Demonstrates that segmentation can help in suitable document settings. It does not establish a need to summarize or split single-sentence scene descriptions, and introduces additional representation choices. |
| Anthropic, **Introducing Contextual Retrieval**, 19 September 2024. [Primary report](https://www.anthropic.com/research/contextual-retrieval). Engineering report, not a peer-reviewed paper. | Prepends chunk-specific context derived from the containing document before lexical/dense indexing; reports retrieval benefits on its tested corpora. | Distinguish explanatory text from administrative metadata. A caption's parent image ID is useful for provenance but is not descriptive context. Invented donor explanations or target-image labels would add a new information source. |
| Ma et al., **Query Rewriting for Retrieval-Augmented Large Language Models**, EMNLP 2023, pp. 5303–5315. [Paper](https://aclanthology.org/2023.emnlp-main.322.pdf), [record](https://aclanthology.org/2023.emnlp-main.322/). The PDF uses “for”; the current Anthology page title uses “in.” | Rewrite–retrieve–read adapts search queries for frozen retriever/reader components, including a trained rewriter, and evaluates QA. | Query intervention itself is established. Our human image-informed minimal edit is an oracle diagnostic of a naturally occurring decoded-caption error, with generator caption held fixed; it is not an automatic rewriter contribution. |
| Chen, Lin, Han & Sun, **Benchmarking Large Language Models in Retrieval-Augmented Generation**, AAAI 2024, 38(16), 17754–17762; published 24 March 2024. [Paper](https://ojs.aaai.org/index.php/AAAI/article/download/29728/31250), [DOI](https://doi.org/10.1609/aaai.v38i16.29728). | RGB separately tests noise robustness, rejection, integration and robustness to false information. It constructs QA/document conditions rather than neural-caption transitions. | Supports keeping no-retrieval and random-context controls and recording uncertainty. It weakens any broad claim that discovering misleading RAG is novel; the proposed contribution must remain specific to verified brain-decoded errors and the query-only intervention. |
| Rohrbach et al., **Object Hallucination in Image Captioning**, EMNLP 2018, pp. 4035–4045. [Paper](https://aclanthology.org/D18-1437.pdf), [DOI](https://doi.org/10.18653/v1/D18-1437). | CHAIR measures object hallucination using COCO segmentation and caption evidence, restricted in that study to 80 object categories; ordinary caption metrics can miss visual inaccuracies. | Supports direct visual evidence. CHAIR alone cannot evaluate all attributes, actions and relations, and unmodified full-image labels cannot be assumed to describe the displayed NSD crop. Human crop-grounded claims remain primary. |
| SQLite **FTS5 Extension**, official documentation, accessed 28 October 2026. [Documentation](https://www.sqlite.org/fts5.html). | Defines BM25 behavior, unindexed fields, deterministic SQL ordering and external-content index checks; external content is compared during `integrity-check` when rank is set to 1. | Supports unindexed administrative metadata and the corrected integrity check. Algorithm correctness is an engineering improvement, not an independent research novelty claim. |

Our inference from this evidence is that whole-caption indexing is the strongest
default for the present corpus. The offline image-bundle result motivates a
possible later ablation, but does not establish improved factuality or error
correction. We did not run learned semantic chunkers, late-chunking embeddings,
context-generating LLMs or a broad retriever benchmark. Dense retrieval,
human donor-relevance labels and external replication remain blind spots.
